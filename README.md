# HAMODYBR TikTok Lab

Native iPhone app for local MP4/MOV inspection, media timing diagnostics, original/TikTok comparison, and JSON report export.

The first version is read-only. It does not modify, download, or upload videos.

See [the Arabic guide](README_AR.md) for build and usage instructions. The GitHub Actions workflow builds an unsigned IPA for signing on your iPhone with Feather.

Minimum deployment target: iOS 16.
